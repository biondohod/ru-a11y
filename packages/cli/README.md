# ru-a11y-toolkit-cli

> ⚠️ **В разработке** — этот пакет ещё не готов к использованию.

CLI-сканер доступности для проверки готовых страниц на соответствие ГОСТ Р 52872-2019 и Постановлению №102.

Планируемый функционал:
- Сканирование URL через Puppeteer + axe-core
- Отчёт с привязкой к пунктам ГОСТ и Постановления №102
- Форматы вывода: JSON, HTML, консоль
