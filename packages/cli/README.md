# @ru-a11y-toolkit/cli

CLI-инструмент для автоматизированной проверки доступности веб-страниц по российским требованиям:

- ГОСТ Р 52872-2012
- Постановление Правительства РФ №102 от 07.02.2026

Проверка выполняется в headless-браузере (Puppeteer) с использованием `axe-core` как движка автоматизированного анализа.

## Установка

В монорепозитории:

```bash
npm install
```

Локальный запуск CLI:

```bash
npm run build -w packages/cli
node packages/cli/dist/cli.js --help
```

## Быстрый старт

Проверка одной страницы в консоли:

```bash
node packages/cli/dist/cli.js https://example.com
```

Проверка нескольких URL с JSON-отчетом:

```bash
node packages/cli/dist/cli.js https://example.com https://example.com/catalog --format json --output ./reports
```

Проверка URL из файла:

```bash
node packages/cli/dist/cli.js --urls-file ./urls.txt --standard gost-aa --concurrency 3
```

## Справка CLI

```bash
ru-a11y-cli --help
```

Основные флаги:

- `--standard`: `gost-a`, `gost-aa`, `gost-aaa`
- `--wcag-tags`: дополнительная фильтрация правил axe по тегам
- `--format`: `console` (по умолчанию), `json`, `html`
- `--output`: директория для отчетов `json/html`
- `--max-issues`: порог нарушений для завершения с кодом `1`
- `--timeout`: таймаут проверки одной страницы в миллисекундах
- `--concurrency`: число одновременных проверок
- `--include` / `--exclude`: фильтрация нарушений (по внутреннему коду, id правила axe, принципу, серьезности)

## Форматы отчетов

### Консольный отчет

- сводка по количеству проверенных страниц и нарушений;
- группировка нарушений по принципам: воспринимаемость, управляемость, понятность, надежность;
- по каждому нарушению: селектор, внутренний код ru-a11y, id правила axe, ссылки на ГОСТ/ПП №102, рекомендация.

### JSON-отчет

Файл `ru-a11y-report.json` содержит:

- массив страниц;
- нормализованные нарушения (`ruRuleCode`, `axeRuleId`, `gostRefs`, `post102Refs`, `selector`, `description`, `recommendation`).

Этот формат подходит для последующей интеграции с overlay и другими инструментами в рамках `ru-a11y-toolkit`.

### HTML-отчет

Файл `ru-a11y-report.html` содержит:

- общую сводку;
- таблицу нарушений;
- русскоязычные заголовки и подписи.

## Коды выхода

- `0` — проверка завершена, нарушений нет или их количество не превышает `--max-issues`;
- `1` — найдено нарушений больше порога `--max-issues`;
- `2` — внутренняя ошибка CLI или ошибка инфраструктуры проверки.

## Соответствие нормативам

CLI использует `axe-core` как технический движок и поверх него применяет внутренний русскоязычный маппинг `src/mapping/gostMapping.ts`.

Маппинг связывает обнаруженные нарушения с:

- пунктами ГОСТ Р 52872-2012;
- требованиями Постановления №102;
- практическими рекомендациями по исправлению.

Модель маппинга сделана расширяемой: текущий набор правил является базовым и может быть вынесен в отдельный `@ru-a11y-toolkit-core`.
