# ru-a11y-toolkit-overlay

> ⚠️ **В разработке** — этот пакет ещё не готов к использованию.

Runtime-визуализатор ошибок доступности прямо в браузере для React-приложений.

Планируемый функционал:
- Подсветка элементов с нарушениями прямо на странице
- Всплывающие подсказки с описанием нарушения на русском языке и ссылкой на ГОСТ/Постановление №102
- Панель со списком всех найденных нарушений
- Режим «разработка» — включается через env-переменную
